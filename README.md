# EstagioSupervisionadoBANCA_TCC

O presente plano de trabalho descreve o desenvolvimento de um Sistema de Controle de Bancas de TCC, destinado à Coordenação do Curso de Sistemas de Informação (CCET). O sistema visa automatizar e gerenciar o agendamento de defesas, controlando a disponibilidade de laboratórios e salas, além de gerenciar os horários de discentes, orientadores e professores convidados para a banca. As principais atividades incluem o desenvolvimento de módulos para a prevenção de choques de horários (tanto para os espaços físicos quanto para os docentes envolvidos), a criação de um sistema de gestão de solicitações com histórico e moderação exclusiva pela coordenação, e a automatização da emissão de documentos padrão para a participação nas bancas. Espera-se obter um sistema funcional e íntegro que otimize o fluxo de trabalho da coordenação, garantindo organização na alocação de recursos e maior agilidade na burocracia documental.
